# Muhammad Parvaiz — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — design and responsive layout
- `script.js` — menu, scroll reveal and cursor effect
- `assets/profile.jpg` — add your professional photo here
- `assets/Muhammad_Parvaiz_CV.pdf` — add your latest CV here

## Before publishing
Replace these placeholders in `index.html`:
- `your-email@example.com`
- GitHub URL
- LinkedIn URL

Add:
- your professional photo as `assets/profile.jpg`
- your latest CV as `assets/Muhammad_Parvaiz_CV.pdf`

## Run
Double-click `index.html` to preview it, or open the folder in VS Code and use Live Server.

## Publish
This is static HTML/CSS/JS, so it can be hosted on GitHub Pages, Netlify, Vercel, or standard web hosting.
